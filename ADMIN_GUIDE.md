# Admin quick guide
Sign in at /account then open /admin. Owner can edit settings and assign roles; Staff can manage operational records.
- Overview: counts, returned order value, low total stock and order status bars.
- Inventory: Add new, enter name/category/daily price/stock/specs and upload images. Active controls visibility; Featured controls homepage. Use hide instead of delete for rented equipment.
- Categories: maintain category names; update matching inventory records when renaming.
- Packages: select quantities from inventory and choose a bundle price. The public page calculates savings.
- Orders: find request by customer or number; confirm after contacting customer, then mark Picked up, Returned or Cancelled. Cancel abandoned Pending bookings. Print receipt to PDF via browser. Never reduce stock below existing commitments.
- Customers: view registered profiles and order counts. Guest orders appear in Orders.
- Messages: read contact submissions, toggle read status or reply by email.
- Guides: add article text and cover; Owner can disable entire guide in Settings.
- Subscribers: export CSV for launch notifications; obtain consent before marketing.
- Settings: edit business and contact details, logo, hero URL, map embed, hours, visibility, deposit, delivery and Place ID. API key stays server-side in environment variables.
- Users: assign existing Auth user UUID as Owner or Staff. Keep at least one Owner.
